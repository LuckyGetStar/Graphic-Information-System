# Graphic-Information-System
Demo Studi Kasus GIS

1. Judul Proyek
Sistem Informasi Geografis untuk Pemetaan dan Monitoring Aset Infrastruktur Berbasis Web

2. Latar Belakang
   
Pengelolaan aset infrastruktur membutuhkan informasi mengenai lokasi, jenis, kondisi, dan status aset agar proses pemeliharaan dapat dilakukan dengan lebih efektif. Jika data aset hanya disimpan dalam tabel, pengguna akan kesulitan mengetahui persebaran aset dan menentukan lokasi yang perlu diprioritaskan.
Oleh karena itu, dibangun sebuah sistem GIS berbasis web yang menampilkan lokasi aset pada peta digital. Sistem ini menggunakan HTML, CSS, JavaScript, dan library Leaflet untuk menampilkan peta interaktif. Data aset disimpan dalam struktur data JavaScript dan dapat ditampilkan berdasarkan jenis serta kondisi aset.
Studi kasus ini merupakan simulasi pembelajaran berdasarkan penerapan GIS dalam asset and property management, sebagaimana dijelaskan pada materi pemateri.

4. Rumusan Masalah
1. Bagaimana menampilkan lokasi aset infrastruktur dalam bentuk peta digital?
2. Bagaimana memberikan informasi jenis dan kondisi setiap aset?
3. Bagaimana membantu pengguna mengidentifikasi aset yang membutuhkan pemeliharaan
   
5. Tujuan Proyek
- Membuat peta digital yang menampilkan persebaran aset infrastruktur.
- Menyajikan informasi aset melalui penanda lokasi (marker).
- Menyediakan fitur penyaringan data berdasarkan kondisi aset.
- Menerapkan pemrograman web untuk mendukung pengelolaan data geografis.
